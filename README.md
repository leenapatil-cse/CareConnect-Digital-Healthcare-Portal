# CareConnect-Digital-Healthcare-Portal
Digital Healthcare Portal using Agile development with patient and doctor modules, appointments, medical reports and doctor-patient communication.

## Project Overview
The Digital Healthcare Portal is a web-based application designed to improve communication between patients and doctors and make basic healthcare services easier to access and manage.

The portal provides separate interfaces for patients and doctors, allowing patients to request appointments, upload medical reports, and communicate with doctors.

## Objectives
- Provide a digital platform for patients and doctors.
- Simplify appointment management.
- Allow patients to upload and view medical reports.
- Enable doctor-patient communication.
- Maintain patient information and appointment records.

## Features
- Patient and doctor login
- Patient dashboard
- Patient profile management
- Appointment booking and cancellation
- Medical report upload and viewing
- Doctor dashboard
- Appointment status updates
- Doctor-patient messaging
- Form validation and error handling

## Technologies Used
- HTML
- CSS
- JavaScript
- Browser Local Storage

## Agile Methodology
The project follows Agile Software Development principles. Development is divided into smaller tasks and features, which are planned, implemented, tested and reviewed incrementally.

## Testing
Manual testing is performed to verify login, appointment management, medical report uploads, communication and input validation.

## Disclaimer
This project is an academic prototype. It uses sample data and is not intended for actual medical diagnosis, treatment or storing real patient information.
