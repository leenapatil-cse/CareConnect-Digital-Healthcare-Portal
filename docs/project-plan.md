# Digital Healthcare Portal - Project Plan

## Sprint 1 Goal
Develop a functional healthcare portal prototype.

## Planned Features
- Patient login
- Doctor login
- Patient profile
- Appointment booking and cancellation
- Medical report upload
- Doctor-patient messaging
- Role-based access

## Team Workflow
Tasks are divided among team members and developed incrementally.

## Testing
Features are manually tested for functionality, validation and expected behavior.
